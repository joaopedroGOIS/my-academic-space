# My Academic Space

Quero criar uma aplicação web chamada provisoriamente de Meu Espaço Acadêmico.

Este projeto será inicialmente uma ferramenta pessoal para me auxiliar na organização da faculdade e dos estudos. O foco principal de uso será em desktop e notebook, mas a aplicação também deve ser responsiva para celular.

OBJETIVO DESTA PRIMEIRA ETAPA

Nesta primeira etapa, NÃO tente desenvolver todas as funcionalidades completas.

Quero que você construa primeiro:

A estrutura geral da aplicação

O layout principal

A navegação entre os módulos

A Home

As páginas vazias ou estruturais dos demais módulos

Um design consistente e moderno

Podemos utilizar dados fictícios inicialmente para demonstrar o funcionamento visual.
